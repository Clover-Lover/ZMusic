# 动作与响应

宿主调用：

```json
{
  "source": "wy",
  "action": "musicUrl",
  "info": {
    "type": "320k",
    "musicInfo": {}
  }
}
```

`musicInfo` 的字段见 [歌曲对象](./04-歌曲对象.md)。

脚本的返回值先经过预加载校验，再交给播放器。校验失败统一变成错误 `failed`，不把非法字符串交给播放器。

## `musicUrl`

在线歌曲和本地歌曲都会走这一动作。

| | |
|---|---|
| `info.type` | 在线歌曲是音质：`128k`、`320k`、`flac`、`flac24bit`。本地歌曲的调用点传入 `null` |
| 脚本返回 | 字符串。长度不超过 2048，且匹配 `^https?:` |
| 播放器最终拿到 | `{ type, url }`。`type` 是这次请求的音质，`url` 是脚本返回的字符串 |

## `lyric`

只有 `local` 会注册。`info.type` 在这里是源类型 `'music'`，不是音质。

脚本返回对象。`lyric` 必须是字符串。

| 字段 | 限制 | 不合格时 |
|---|---|---|
| `lyric` | 字符串，长度不超过 51200 | 整次失败 |
| `tlyric` | 字符串且长度小于 5120 | 变成 `null` |
| `rlyric` | 字符串且长度小于 5120 | 变成 `null` |
| `lxlyric` | 字符串且长度小于 8192 | 变成 `null` |

播放器拿到的就是校验后的这个对象。

## `pic`

只有 `local` 会注册。`info.type` 同样是 `'music'`。

脚本返回规则与 `musicUrl` 相同：不超过 2048 字符的 `http` 或 `https` 字符串。播放器直接使用该字符串作为图片地址。

## 不在这套协议里的接口

脚本不能通过动作提供搜索、歌单、专辑、评论或榜单。这些仍调用内置 SDK，例如酷我的 `getMusicUrl` 才会转到 `apis('kw')`，它的 `getLyric` 不会。

因此自定义音源没有与 [网易云接口](../netease-new/INDEX.md) 相当的路径列表。公开脚本仓库里的文件也是这种脚本，不是另一套可逐条调用的 HTTP 文档。
