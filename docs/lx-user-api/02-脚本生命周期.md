# 脚本生命周期

脚本跑在预加载环境里。可用对象是 `globalThis.lx`，版本号 `lx.version` 为 `2.0.0`，`lx.env` 为 `mobile`。`eval` 和 `Function` 构造被关掉。

## 启动时必须发送 `inited`

```js
lx.send(lx.EVENT_NAMES.inited, {
  sources: {
    kw: { name: 'kw', type: 'music', actions: ['musicUrl'], qualitys: ['128k', '320k'] },
  },
})
```

`sources` 的键只能是 `kw`、`kg`、`tx`、`wy`、`mg`、`local`。每一项要求：

| 字段 | 要求 |
|---|---|
| `type` | 必须是 `'music'`，否则这一项被跳过 |
| `actions` | 见下表，脚本多报的会被滤掉 |
| `qualitys` | 见下表，脚本多报的会被滤掉 |

| 源 | 保留的动作 | 保留的音质 |
|---|---|---|
| `kw` `kg` `tx` `wy` `mg` | `musicUrl` | `128k` `320k` `flac` `flac24bit` |
| `local` | `musicUrl` `lyric` `pic` | 无。脚本报的音质会被滤成空列表 |

`xm` 不在初始化遍历里，写了也不会注册。类型 `Quality` 里还有 `192k`、`ape`、`wav`，自定义源初始化时同样会被滤掉。

`inited` 只能发一次。缺 `sources` 或遍历抛错时，初始化失败，应用弹出脚本名和错误信息，并改回一个未禁用的内置源。

初始化成功后，应用把滤过的音质表记下来，并把三个动作接到播放流程。宿主向脚本要结果的超时是 20 秒。

## 监听请求

```js
lx.on(lx.EVENT_NAMES.request, ({ source, action, info }) => {
  return Promise.resolve(/* 见动作与响应 */)
})
```

没注册 `request` 时，这次调用返回失败，错误信息是 `Request event is not defined`。处理函数抛错或拒绝时，错误的 `message` 回给播放器。

## 更新提示

`lx.send(lx.EVENT_NAMES.updateAlert, { log, updateUrl })` 只能发一次。`log` 必填，最长 1024，超出截断并加 `...`。`updateUrl` 须是 http(s)，且长度不超过 1024，否则丢掉。用户是否看到提示还取决于该脚本的 `allowShowUpdateAlert`，导入时默认为开。
