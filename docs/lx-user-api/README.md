# 洛雪自定义音源

对照 [lx-music-mobile](https://github.com/lyswhut/lx-music-mobile) `fb84807`（v1.9.1）。自定义音源链接下载的是一段 JavaScript，不是 [网易云接口文档](../netease-new/INDEX.md) 那种按路径拆开的 HTTP API。

搜索、歌单、评论、榜单仍走应用内置的各平台 SDK。选中某个 `user_api_…` 之后，在线歌曲只把「取播放地址」交给脚本；本地歌曲还可以再要歌词和封面。
