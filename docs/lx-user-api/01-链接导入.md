# 链接导入

设置里有两种导入：本地文件，或在线地址。在线地址必须匹配 `^https?://`。应用把该地址的响应正文当作脚本文本，不按 JSON 解析。

正文超过 9_000_000 字符则拒绝，提示 `Too large script`。列表里最多 20 条。

## 文件头

脚本必须以块注释开头，否则导入失败。应用只读第一段 `/* … */`，用下面的行格式取字段：

```text
 * @字段 值
```

| 字段 | 最长 | 缺省 |
|---|---|---|
| `@name` | 24 | `user_api_` 加当时本地时间 |
| `@description` | 36 | 空 |
| `@author` | 56 | 空 |
| `@homepage` | 1024 | 空 |
| `@version` | 36 | 空 |

超长会截断并在末尾加上 `...`。注释里的其他标签（例如 `@update_url`）导入时丢弃。

入库后生成 id：`user_api_` + 三位随机数字 + `_` + 毫秒时间戳。元数据和脚本文本分开保存。选中这条源时，才把脚本装进独立的 QuickJS 环境。

## 和网易云文档的差别

[网易云接口](../netease-new/INDEX.md) 的每一章是一条 HTTP 路径，例如 `/search`、`/song/url`。自定义音源链接没有路径表。同一个地址永远返回整份脚本；换歌曲、换音质都是应用在脚本里再发一次动作，不会对这个链接追加查询参数。
