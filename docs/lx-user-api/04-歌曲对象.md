# 歌曲对象

动作里的 `info.musicInfo` 是旧字段名的扁平对象，由当前曲目转换而来。

## 所有来源都有

| 字段 | 含义 |
|---|---|
| `name` | 歌曲名 |
| `singer` | 艺术家名 |
| `source` | `kw` `kg` `tx` `wy` `mg` `local` |
| `songmid` | 歌曲 id。米谷来源上这是 copyrightId，本地来源上这是文件路径 |
| `interval` | 时长文本，例如 `03:55`，可以是 `null` |
| `albumName` | 专辑名 |
| `img` | 已有封面地址，没有时是空字符串 |
| `typeUrl` | 空对象 |

## 在线歌曲另有

| 字段 | 含义 |
|---|---|
| `albumId` | 专辑 id，可以没有 |
| `types` | 音质数组，元素为 `{ type, size }`，酷狗元素另有 `hash` |
| `_types` | 以音质为键的同一份信息 |

按来源追加：

| 来源 | 字段 |
|---|---|
| `kg` | `hash` |
| `tx` | `strMediaMid`、`albumMid`、`songId` |
| `mg` | `copyrightId`、`lrcUrl`、`mrcUrl`、`trcUrl` |

`kw` 和 `wy` 没有上表之外的字段。取播放地址时，酷我、酷狗一类脚本通常读 `songmid`，酷狗再读 `hash`。

## 本地歌曲另有

| 字段 | 含义 |
|---|---|
| `filePath` | 文件路径 |
| `ext` | 扩展名 |
| `albumId` | 空字符串 |
| `types` | 空数组 |
| `_types` | 空对象 |
